Download MusicWidget v1
How to install:
  1. Download the widget file.
  2. Open the JSON file and copy all of its contents.
  3. Open Pogly's Widget Creator.
  4. Choose Import.
  5. Paste the widget JSON and load it.
  6. Enter the streamer's Last.fm username.
  7. Customize the colors, opacity, artwork and status options.
  8. Save the widget.
